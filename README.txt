HOW TO OPEN
1. Extract the folder.
2. Open the folder in VS Code.
3. Install Live Server extension if needed.
4. Right-click index.html -> Open with Live Server.

IMPORTANT
This version does NOT take online payments and does NOT have an online checkout.
The quote form prepares an email addressed to Mekepower@gmail.com.
For a production system, connect the quote form to a backend/database so requests are stored and visible to an admin dashboard.

EDITING PRODUCTS
Open js/products.js. Each product follows:
['Category','Product name','Description','Availability','Icon']

BRANDING
The design uses navy, gold and white to match the supplied MEKE logo artwork. The website intentionally uses a corporate B2B catalogue/sourcing style rather than an online-shop checkout style.
